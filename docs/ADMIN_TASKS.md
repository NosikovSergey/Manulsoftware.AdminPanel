# Задачи: Панель администратора

## Приоритеты

### P1 — MVP (без этого панель бесполезна)
1. Аутентификация
2. Поиск пользователей
3. Карточка пользователя
4. Карточка заказа
5. Карточка ключа

Параллельно с P1: изменение в Telegram-боте — добавить проверку статуса пользователя в `AuthorizationMiddleware` для поддержки блокировки.

### P2 — следующий приоритет
6. Управление тарифами
7. Карточка транзакции

---

## 1. Аутентификация

Отдельный модуль входа в панель. Не связан с Telegram-пользователями.

- Страница входа (логин + пароль)
- Сессия: после входа администратор остаётся авторизованным до явного выхода или истечения сессии
- Защита всех разделов панели от неавторизованного доступа
- Страница «Сменить пароль» для текущего пользователя
- Выход из системы

---

## 2. Поиск пользователей

Входная точка для большинства сценариев поддержки.

- Поиск по Telegram ID, username, имени
- Результаты поиска: список пользователей с краткой информацией (имя, username, баланс, статус)
- Переход в карточку пользователя

---

## 3. Карточка пользователя

Центральный экран для работы с конкретным пользователем. Все данные и действия в одном месте.

**Данные:**
- Профиль (имя, username, Telegram ID, дата регистрации, последняя активность)
- Баланс (в том числе отрицательный — отображается как долг)
- Флаг «Пробный период использован»
- Статус (активен / заблокирован)

**Связанные разделы внутри карточки (вкладки):**
- Список ключей пользователя → переход в карточку ключа
- История заказов → переход в карточку заказа
- История транзакций → переход в карточку транзакции

**Действия:**
- Заблокировать / разблокировать — требует добавления проверки статуса в middleware Telegram-бота
- Выдать / забрать права администратора в боте (не влияет на доступ к веб-панели)
- Сбросить пробный период

---

## 4. Карточка ключа

Экран для диагностики и управления конкретным VPN-ключом.

**Данные из двух источников одновременно:**
- Наша база: статус (вычисляется из `IsEnabled` + `ExpiredDate`), дата выдачи, дата истечения, сервер
- Marzban (живые данные): статус (Active / OnHold / Expired / Limited), использованный трафик, общий трафик, дата истечения

Расхождение между источниками подсвечивается.

**Действия:**
- Включить / отключить ключ
- Продлить бесплатно (выбор длительности)
- Восстановить ключ (принудительная синхронизация с Marzban) — активно только при расхождении

---

## 5. Карточка заказа

Экран для просмотра и управления конкретным заказом.

**Данные:**
- Статус заказа
- Тариф (длительность)
- Сумма оплаты (берётся из связанной транзакции списания, не из текущей цены тарифа)
- Связанный ключ → переход в карточку ключа (отсутствует если ключ не был выдан)
- Связанный пользователь → переход в карточку пользователя
- Временны́е метки (создан, оплачен, истекает)

**Действия (зависят от статуса заказа):**
- «Отменить и вернуть деньги» — для зависших заказов (статус Created / Paid)
- «Вернуть деньги» — для активных заказов (статус Issued); ключ отключается, деньги на баланс
- Заказы в статусах Expired / Canceled / Refunded — только просмотр

---

## 6. Карточка транзакции

Экран для просмотра конкретной транзакции и при необходимости её отката.

**Данные:**
- Визуальный тип (производный из `Type` + `Status` в БД):
  - Deposit + Committed → «Пополнение»
  - Withdrawal + Committed → «Списание»
  - Withdrawal + Refunded → «Возврат»
  - Deposit + Refunded → «Откат пополнения»
- Сумма
- Источник: Telegram Stars / СБП / Банковская карта / — (для внутренних операций)
- Статус: «В обработке» / «Проведена» / «Отменена» / «Возвращена»
- Дата и время

**Действия:**
- «Откатить транзакцию» — только для Deposit + Committed (пополнение при чарджбэке); баланс может уйти в минус

---

## 7. Управление тарифами

Самостоятельный раздел, не привязан к конкретному пользователю.

**Данные:**
- Список всех тарифов: длительность, цена, статус (включён / выключен), отметка «лучший выбор»
- Пробный тариф не отображается

**Действия (инлайн в таблице):**
- Изменить цену — инлайн редактирование поля
- Включить / выключить тариф — toggle
- Поставить / снять отметку «лучший выбор» — чекбокс

---

## Связи между модулями

```
Поиск пользователей
    └── Карточка пользователя
            ├── Карточка ключа
            ├── Карточка заказа
            │       └── Карточка ключа
            └── Карточка транзакции

Тарифы (отдельный раздел)
Смена пароля (отдельный раздел)
```

---

## Зависимости вне панели

- **Блокировка пользователя** требует изменений в Telegram-боте: добавить проверку поля `Status` в `AuthorizationMiddleware`
- **Сброс пробного периода** требует нового метода в сервисе пользователей
- **Откатить транзакцию пополнения** — логика уже есть в `RefundTransactionAsync`, применима к Deposit + Committed
