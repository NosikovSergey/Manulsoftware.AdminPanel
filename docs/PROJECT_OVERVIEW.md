# Обзор проекта VpnBot

## Что это

Telegram-бот для продажи VPN-доступа. Пользователь взаимодействует исключительно через Telegram: выбирает тариф, пополняет баланс, получает ключ для подключения. Никакого отдельного сайта для конечного пользователя нет.

---

## Пользователи

Пользователь регистрируется автоматически при первом обращении к боту. Никакой отдельной формы регистрации нет.

У каждого пользователя есть:
- Профиль (имя, username из Telegram)
- Внутренний баланс в рублях — с него списывается оплата подписки
- История заказов и транзакций
- Статус: активен или заблокирован

Бот поддерживает два языка: русский и английский. Язык определяется автоматически по настройкам Telegram.

### Пробный период

Новый пользователь может активировать бесплатный пробный доступ на 1 день. Это одноразовая акция — повторно воспользоваться ею нельзя.

### Пользовательское соглашение

При первом визите бот запрашивает принятие пользовательского соглашения и политики конфиденциальности. До принятия пользователь не может пользоваться ботом.

---

## Тарифы

Тариф определяет длительность подписки и её стоимость. Доступные длительности: 1 месяц, 3 месяца, 6 месяцев, 1 год. Один тариф может быть помечен как «лучший выбор» — он выделяется в интерфейсе.

Тарифы можно включать и выключать. Выключенный тариф пользователям не показывается.

Отдельно существует пробный тариф (1 день), он не отображается в общем списке — доступен только через кнопку «Попробовать бесплатно».

Каждый тариф привязан к конкретному VPN-серверу и стране.

Лимит трафика на любом тарифе — **300 ГБ**.

---

## Пополнение баланса

Пользователь пополняет внутренний баланс, после чего списывает с него стоимость подписки. Доступны три способа оплаты:

- **Telegram Stars** — внутренняя валюта Telegram, конвертируется в рубли по курсу
- **СБП QR-код** — оплата через систему быстрых платежей
- **Банковская карта**

Платежи через СБП и карту обрабатываются через платёжный шлюз **Platega**. После успешной оплаты баланс пополняется автоматически.

---

## Заказы и ключи доступа

Когда пользователь выбирает тариф и подтверждает покупку, создаётся заказ. Оплата списывается с баланса, после чего система автоматически выдаёт ключ доступа.

Ключ доступа — это ссылка для подключения к VPN (протокол VLESS). Пользователь копирует её и вставляет в VPN-клиент.

### Статусы заказа

| Статус | Значение |
|---|---|
| Создан | Заказ оформлен, ожидает обработки |
| Оплачен | Средства списаны |
| Выдан | Ключ получен, подписка активна |
| Истёк | Срок подписки закончился |
| Отменён | Заказ отменён |
| Возвращён | Средства возвращены на баланс |

### Продление

Если у пользователя уже есть активная подписка, при повторной покупке срок действия ключа продлевается, а новый ключ не создаётся.

---

## Реферальная программа

У каждого пользователя есть реферальная ссылка. Когда привлечённый пользователь оплачивает подписку, реферер автоматически получает процент от суммы на свой баланс.

---

## Администраторы

Отдельного веб-сайта для администраторов пока нет — сейчас базовые команды доступны прямо в боте (через команды `/give_admin`, `/user_keys`, `/balance` и другие). Признак администратора хранится в профиле пользователя.

Планируется отдельная веб-панель администратора. Подробнее о её функциональности — в файле `ADMIN_PANEL.md`.

---

## VPN-инфраструктура

VPN-серверы управляются через панель **Marzban**. Каждый сервер привязан к стране. При выдаче ключа система автоматически создаёт пользователя в Marzban и генерирует ссылку для подключения.

Когда срок подписки истекает, ключ автоматически отключается. За несколько дней до истечения пользователь получает напоминание в боте.

---

## Фоновые задачи

Ряд процессов выполняется автоматически в фоне:
- Выдача ключей после оплаты
- Отключение истёкших ключей
- Уведомления об истекающих подписках
